## Collaboration rules

- Work on the branch assigned to you.
- Use clear commit messages that describe the change.
- Do not overwrite another member's work without discussion.
- Submit changes through Pull Requests when possible.
- Test the application before asking for a merge.
- The team should understand and be able to explain every part of the submitted code.
